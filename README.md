\## How to run (Java)

Most items can be compiled and run directly with `javac` / `java`.



Example pattern:



&nbsp;   # compile

&nbsp;   javac path/to/File.java



&nbsp;   # run (class name must match the public class)

&nbsp;   java File



> Some folders include a local README with exact commands and expected output.



\## Conventions

\- Java source files follow standard naming (`ClassName.java`).

\- Each curated item aims to include:

&nbsp; - brief explanation of approach

&nbsp; - time/space complexity

&nbsp; - edge-case notes

&nbsp; - demo usage (`main`) and/or tests where useful
