\# LeetCode Practice



A set of LeetCode solutions in Java, organized by topic, with brief explanations and complexity notes.



\## Conventions (per solution)

Each solution includes:

\- Problem name + link

\- Brief approach summary

\- Time/space complexity

\- Notes on edge cases



\## Organization

Solutions are grouped by topic:

\- `arrays/`

\- `hashmap/`

\- `two-pointers/`

\- `stacks-queues/`

\- `linked-lists/`

\- `trees/`

\- `graphs/`

\- `dp/`



\## File naming

`<problem-number>-<problem-name>.java`  

Example: `217-contains-duplicate.java`



\## Quality bar

Where helpful, solutions include a small set of self-check inputs/outputs (in `main()` or as comments).
